# Design fidelity audit — canvas vs. code

Audited 2026-08-07 on branch `audit/design-fidelity` (from `main` @ `2ef0921`).
Authority: `planning-reference/design/folio-v2.html` (read per-frame from the
bundle's decompressed template — frames S0, 0M, B6a ×3, B8a, C9–C12, D13–D15,
G20, G21). App evidence: source inspection plus a live walk against the dev
stack, signed in as a **seeded realistic account** (`audit.reader@example.com`:
ten books, eight real genres, seven finishes spread Jan–Jul 2026, four
reflections with ratings) — not the degenerate demo data.

**Evidence limits.** Ollama was unreachable throughout, so AI _loaded_ states
(B8a chip content, D15 report body, G20 narrative text) were verified from
code + canvas, not exercised live; their loading/failed/degraded branches were
exercised live (Ollama down is exactly what those branches render).
Screenshots were unavailable (browser pane not compositing); layout claims come
from the accessibility tree and computed geometry, which is stronger evidence
for the one rendering bug below anyway.

Severity: **structural** (section/state/control missing) · **visual** (present
but wrong) · **copy** · **motion** (vs 0M). Est: XS <½h · S ½–2h · M half-day
· L day+.

## Answered questions from the brief

**"Where you read" (Metrics.tsx:202).** The heading is **faithful**. In the
canvas, "Where you read" appears exactly once in all 81 frames — directly over
the genre donut (conic segments labelled Lit. fiction 34% / Mystery / Memoir /
Poetry / Everything else). No location field, capture, or concept exists
anywhere in the canvas (B6a's form has none). The heading is the design's own
editorial label for the genre breakdown; the code renders exactly that. No
change needed — any renaming would be a design decision, not a fidelity fix.

**Velocity bar.** As audited, it never rendered — finding #1 (since fixed; see
the Remediation record). The CSS percentage-height bug zeroed every bar for
every account; the demo's single-month data merely made it look like a data
problem.

  Tailwind tokens matching the spec byte-for-byte; shimmer loops at 1.6s; the
  global `prefers-reduced-motion` rule kills every loop and travel (stricter

  (scrim + surface + sheet + retire-exit) on E18 and the admin dialogs.
